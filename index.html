Explorando Métodos Privados no Python

No Python, o encapsulamento é atingido principalmente via convenções de código e Name Mangling.

Exemplo de Código


class Dispositivo:
    def __init__(self, nome):
        self.nome = nome

    # Convenção: Uso interno
    def _conectar_rede(self):
        print("Conectando...")

    # Name Mangling: Dificulta acesso externo
    def __autenticar(self):
        print("Autenticando credenciais...")
